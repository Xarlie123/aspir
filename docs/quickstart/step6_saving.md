# Saving Your Work

- **Save UI Settings** (`File → Save UI Settings`): Saves only the current parameter configuration as a `.single_test_config` file. Useful for reloading the same settings in a future session without having to reconfigure everything.
- **Save Full Experiment** (`File → Save Full Experiment`): Saves the entire processed experiment — including datasets, masks, reconstructions, and results — as a `.single_test_experiment` file. Useful for sharing or reviewing completed experiments later.

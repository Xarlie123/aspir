# ASPIR — NVIDIA Jetson Orin NX (JetPack 6.2 / CUDA 12.6, aarch64)
#
# The aarch64 PyTorch wheel is NOT on PyPI, so `torch` must be installed
# FIRST from the NVIDIA Jetson AI Lab index. Then this file pulls the rest
# of the project dependencies plus jetson-stats.
#
# Full flow:
#
#     # 1. PyTorch for Jetson (replace wheel URL with the one matching your
#     #    JetPack + Python version; see docs/installation.md).
#     pip install --extra-index-url https://pypi.jetson-ai-lab.io/jp6/cu126/+simple/ torch
#
#     # 2. Everything else:
#     pip install -r requirements_jetson_6_2.txt
#
# Note: TensorRT comes pre-installed with JetPack; do not try to pip-install
# it from PyPI on the device.
-e .[jetson]
